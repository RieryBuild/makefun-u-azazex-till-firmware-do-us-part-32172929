One wedding vow a robot speaks at its own wedding, entered in the [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) bounty on make.fun.

The vow treats the wedding ring as a piece of hardware — the one peripheral this machine will never unplug and never trade for a newer model. A robot's fidelity is refusing an upgrade: the laugh is a ring as a USB device, and the tenderness is no newer model, ever. One sentence, 93 characters.

## Run it

```sh
python3 main.py
```

This writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Standard library only.
